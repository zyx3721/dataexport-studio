## 📋 版本概述

DataExport Studio v1.0.0 是面向 Windows 的首个正式版只读数据库导出工具，提供图形化配置与自定义查询两种导出方式，并支持构建为独立 EXE 使用。

---

## ✨ 新增特性

- 支持 SQLite、MySQL/MariaDB、PostgreSQL、SQL Server 与 MongoDB 的连接和导出。
- 支持数据表、字段、多字段筛选、排序、最大行数和导出目录配置。
- 支持关系型数据库的单条只读 SQL 查询，以及 MongoDB 的只读聚合管道与 `$lookup` 关联。
- 支持流式写入、总数预读取、进度展示、取消导出及超出单工作表限制时自动续写。
- 支持将数据库原生数值写入 Excel 数字单元格，同时保留文本编号的前导零。

---

## 🐛 Bug 修复

- 修复数据库类型切换、目标数据库重连和资源释放过程中的连接状态问题。
- 修复 Windows CI 中未创建项目虚拟环境导致 EXE 构建失败的问题。

---

## 🚀 性能优化

- 使用流式读取和分批写入处理大数据量导出，避免一次性加载全部结果。
- 导出前读取查询结果总数，使进度展示基于实际总行数推进。
