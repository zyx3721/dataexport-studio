# v1.0.0 发布说明

发布日期：2026-08-01

## 版本概述

DataExport Studio 首个正式版本，提供面向 Windows 的只读数据库导出能力，并可构建为独立 EXE 使用。

## 新增特性

- 支持 SQLite、MySQL/MariaDB、PostgreSQL、SQL Server 和 MongoDB 数据库连接与导出。
- 支持图形化选择数据表、字段、多字段筛选、排序和最大导出行数。
- 支持 SQL 数据库的自定义只读 SQL 查询，以及 MongoDB 自定义聚合导出。
- 支持大数据量流式导出、记录总数预读取、进度展示和取消导出。
- XLSX 导出包含表头样式、完整单元格边框和多工作表续写；数值与文本前导零可按数据类型保留。
- 提供连接切换、资源释放和关闭程序时的导出保护。

## 构建与发布

- 提供 Windows EXE 本地打包脚本，可选用 `assets/icons/app.ico` 作为应用图标。
- 新增 GitHub Actions 发布流程：推送 `v*` 标签后自动运行测试、构建 Windows AMD64 EXE、生成 SHA256 校验文件并创建 GitHub Release。
- GitHub Release 产物统一采用英文文件名：`dataexport-studio_<版本号>_windows_amd64.exe`。

## 兼容性说明

- 仅支持 Windows 系统。
- Python 运行环境要求 3.9 或更高版本。
- SQL Server 使用 `pymssql`，不依赖本机 ODBC 驱动；MongoDB 驱动兼容 MongoDB 4.0 等旧版本服务。
